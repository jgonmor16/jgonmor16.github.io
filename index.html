    HDL tooling for Neovim

    Three merged pull requests on the editor tooling for hardware description languages. VHDL had no indent query in Neovim, so every buffer fell back to a Vimscript file written for the 1993 standard. Wrote the query, anchored so the indent cannot compound, with thirteen reference files testing it as a no-op. Two language-server root fixes merged alongside it.

How I got here

Professional Background

I started in research, building PCIe communications architecture for FPGA fault injection at the University of Seville, with a stint at ITSOFT prototyping IoT systems and demoing them to customers. After that I led the FPGA development for a Star Tracker, then moved into running programmes around that work as a Technical Project Manager, led the software engineering team, and finally transitioned to PM Officer, responsible for the full customer portfolio. I still write the code; the projects above are what that looks like now.
